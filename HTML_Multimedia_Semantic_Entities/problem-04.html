Course Title

Full Stack Web Development

This course introduces learners to the fundamentals of modern web development. Students will learn HTML, CSS, JavaScript, databases and basic web application development.

Course Objectives

  • Understand the fundamentals of web development.
  • Create structured web pages using HTML.
  • Understand basic CSS concepts.
  • Learn JavaScript fundamentals.
  • Understand databases and web applications.
  • Build a basic web development project.

Formatted Course Notes

HTML is used to create the structure of a web page.

Semantic HTML helps developers create meaningful and well-structured web pages.

Important: Always use proper HTML elements according to the purpose of the content.

Example of a code element: <h1>Hello World</h1>

A basic web page follows the structure: HTML → CSS → JavaScript
